# Changelog Withings

> **Information**
>
> En l'absence de détail fonctionnel, une mise à jour concerne uniquement la documentation, les traductions ou des ajustements internes.

# 24/08/2026

- Migration de l'authentification OAuth Withings et des appels API vers les services cloud Jeedom.
- Suppression des identifiants OAuth locaux, de la page de retour OAuth et de la fenêtre d'autorisation devenus obsolètes.
- Les mesures Withings utilisent désormais l'unité fournie par l'API afin de restituer les valeurs correctement.
- Le mode push souscrit et révoque l'ensemble des profils de notification nécessaires.
